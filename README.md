# 달마루 모험기

달마루 마을의 소년 **마루**가 목검 하나 들고 숲지기를 달래러 떠나는 탑다운 액션 RPG입니다.
마을 우물이 마른 까닭을 따라 들판에서 달빛 조각 셋을 모으고, 숲 안쪽 빈터의 대왕멧돼지와 맞섭니다.

▶ 바로 하기: https://minhyuk94.github.io/dalmaru/ (PC 키보드·게임패드, 휴대폰은 화면 버튼)

## 조작

| 키 | 하는 일 |
| --- | --- |
| 방향키 / WASD | 걷기 (8방향) |
| Z / J / Enter | 휘두르기 (빠르게 두 번 = 2연타), 말 걸기·조사 |
| X / K / Space | 구르기 (구르는 동안 무적) |
| C / L | 약초 먹기 |
| Esc / P | 잠깐 쉬기 (소리 끄기, 처음 화면) |

## 들어 있는 것

- 지도 셋: 노을 진 **달마루 마을**, 넓은 **솔바람 들판**, **숲지기의 빈터**
- 적: 통통 뛰는 버섯돌이, 거리를 두고 불씨를 쏘는 도깨비불, 노려보다 돌진하는 멧돼지, 대왕멧돼지(돌진·내리찍기 충격파·부하 부르기)
- 손맛: 칼 호, 맞을 때 번쩍임·멈칫(히트스톱)·화면 흔들림·숫자, 구르기 무적, 넉백
- 마을 사람 대사가 진행에 따라 바뀜, 대장간에서 목검 강화·약초 구입, 상자·덤불·항아리
- 자동 저장(지도를 옮길 때), 이어하기

## 어떻게 만들었나

- 엔진: Godot 4.6 (GDScript), 웹으로 내보내 GitHub Pages에 올림
- **그림·소리·지도를 모두 코드로 만듭니다.**
  - `tools/art/` — 팔레트 + 글자 그림(캐릭터) + 절차적 그리기(나무·바위·기와집·물결). 바닥은 모서리 4칸으로 타일을 고르는 이중 격자 방식
  - `tools/sound/` — 사각·삼각·톱니파와 잡음을 섞어 효과음과 5음계 배경음을 합성
  - `tools/maps/` — 길·연못·숲을 그려 `data/maps.json`으로
- 규칙 계산은 `scripts/rules.gd`, 테스트는 `tests/run_tests.gd`
- GitHub Actions: 생성기 다시 돌리기 → 테스트 → 켜지는지 확인 → 웹 내보내기 → Pages 배포
- 글꼴: [갈무리](https://github.com/quiple/galmuri) (SIL OFL 1.1)
